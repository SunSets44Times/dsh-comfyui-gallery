# ComfyUI Gallery

面向 DeepSeek Harness（DSH）的 ComfyUI 图库插件。从 DSH 左侧栏打开，浏览生成图片、查看生成参数、管理提示词和 LoRA，并把图片或模型信息带回当前对话。

## 功能

- 图片图库：缩略图、详情、大图预览、搜索、排序、目录筛选和分页。
- 目录树与分组：目录按层级展开并显示数量；可按日期（今天/昨天/最近 7 天/按月份）或按项目目录分组，日期可直接跳到某一天。
- 生成信息：正向提示词、负向提示词、采样参数、尺寸、模型、LoRA、工作流和原始元数据。
- 工作流列表：按节点结构与模型归组已保存的工作流，例图取自最近一次出图，逐节点给出中文名称与关键参数，可导出 JSON。
- 图片整理：收藏、评分、自定义标签、备注和批量选择。
- 删除图片：单张或批量删除原图，二段确认，同步清理索引与缩略图缓存。
- 对话操作：把选中的图片、提示词或 LoRA 信息加入当前对话草稿。
- 提示词反推：使用本地 WD14 模型进行单图、上传图片和批量反推。
- 反推记录：任务在后台运行，切换页面后仍可查看进度和结果。
- LoRA 库：读取本地 LoRA，显示元数据和预览图，支持分类、收藏、标签筛选和资料抓取。
- 相似图分组：使用 pHash 或本地 CLIP 查找近似图片和相似构图。
- 工作流复用：编辑已有参数并提交到 ComfyUI 工作台。
- 本地优先：图片、模型文件和用户数据保留在本机。

## 环境要求

- DeepSeek Harness（DSH）桌面版
- Node.js 20 或更高版本
- ComfyUI
- Windows、Linux 或 macOS
- 使用提示词反推时，需要带 Pillow、NumPy 和 ONNX Runtime 的 Python 环境
- 使用 CLIP 相似图分组时，需要兼容的 CLIP Vision 模型和 Python 依赖

插件没有第三方 Node.js 运行时依赖，也不需要构建步骤。

## 安装

从 npm 安装（推荐）：

```powershell
dsh plugin --profile web add dsh-comfyui-gallery
```

也可以在 DSH 左侧栏点击 **插件 → 添加插件**，直接输入包名 `dsh-comfyui-gallery`。桌面端和网页版操作一致。

从源码安装：将仓库克隆到 DSH 配置目录下的插件目录：

```text
<DSH profile>/plugins/dsh-comfyui-gallery
```

在仓库目录运行：

```powershell
./scripts/install.ps1
```

脚本会添加 DSH 插件入口、加入 HMR 监视范围，并为已有配置创建备份。安装完成后重启 DSH，或按 DSH 提示重新加载插件，然后从左侧栏打开 **ComfyUI 图库**。

如果 DSH 安装目录不同，可以指定路径：

```powershell
./scripts/install.ps1 -Workspace "<DSH profile>/plugins/dsh-comfyui-gallery" -Profile "<DSH profile>"
```

## 配置

插件默认查找 ComfyUI 的输出目录和模型目录。需要自定义路径时，在 DSH 用户数据目录创建：

```text
<DSH user data>/dsh-comfyui-gallery/config.json
```

示例：

```json
{
  "roots": ["<ComfyUI>/output"],
  "loraRoots": ["<ComfyUI>/models/loras"],
  "comfyRoot": "<ComfyUI>",
  "python": "<Python executable>",
  "thumbMax": 480,
  "pageSize": 60,
  "warmCount": 300,
  "scanIntervalMs": 30000
}
```

| 字段 | 说明 |
| --- | --- |
| roots | 图片根目录数组。 |
| loraRoots | LoRA 根目录数组。 |
| comfyRoot | ComfyUI 根目录。 |
| loraManagerRoot | SD-LoRA-Manager-Portable 根目录。 |
| workflowRoots | 工作流目录数组，默认自动探测 ComfyUI 的 `user/default/workflows`。 |
| python | 缩略图和反推使用的 Python。 |
| thumbMax | 缩略图最长边，默认 480。 |
| pageSize | 列表分页数量，默认 60。 |
| warmCount | 启动时预热的图片数量，默认 300。 |
| wd14ModelDir | 额外 WD14 模型目录。 |
| similarityModel | CLIP Vision 模型路径。 |
| interrogateTimeoutMs | 单张反推超时时间，默认 180000 毫秒。 |
| workflowFromImages | 工作流页是否列出「从未存盘、只存在于图片元数据里」的工作流，默认 `false`（只列已保存的 .json）。也可以在工作流页直接勾选「包含未存盘的工作流」，选择会存到 `~/.dsh-comfyui-gallery/settings.json`，重启后仍然生效。 |

配置文件只保存在本机，不要提交到公共仓库。

## 提示词反推

图片详情和上传图片面板支持本地 WD14 反推。插件可识别配对的 ONNX 与 CSV 文件、ComfyUI-WD14-Tagger 模型目录，以及 SD-LoRA-Manager 兼容模型目录。

支持标签阈值、排除标签、格式化、单图、上传图片、批量任务、复制结果、下载 caption、取消任务和历史记录。WD14 主要输出画面标签，不会恢复原始 seed、LoRA 权重或作者未公开的提示词。

## LoRA 库

LoRA 库会扫描 ComfyUI 和可选的 LoRA Manager 目录，读取 safetensors 文件头、同名 JSON、Civitai 信息文件和本地预览图。

支持底模、作者、版本、触发词、训练信息、自定义分类、收藏、备注、来源标签、标签筛选、分页、批量抓取公开元数据和预览图，以及将 LoRA 调用信息加入当前对话。插件不加载或修改原始模型权重。

## 工作流列表

左侧栏进入工作流页，列出已保存的 ComfyUI 工作流文件，并用该工作流最近一次出图作为例图。

归组依据是图结构而不是文件：节点类型、连线和用到的模型共同决定身份，seed、步数、CFG、提示词文字和节点坐标都不参与，所以同一个模板换 seed 或改提示词仍是一条记录；换底模或 LoRA 才算另一个工作流。打开图片即可查看它的全部出图，也可以导出或复制工作流 JSON。

打开工作流详情可查看三块内容：用到的底模、扩散模型、文本编码器、VAE 等模型文件；每个 LoRA 的文件名与模型／CLIP 强度；以及完整节点清单。

节点清单按加载、采样、条件、潜空间、图像、工具分组，逐条给出中文名称、作用说明和关键参数（步数、CFG、采样器、文件名前缀等）。常见节点内置了说明，未收录的自定义节点保留类型名并显示前几项参数，不会被隐藏。

ComfyUI 的子图（subgraph）会被展开成内部节点，并标注所属子图名，否则打包在子图里的 LoRA 和模型无法被识别。

只出过图、从未保存过的工作流默认**不列出**。工作流页工具栏有一个「包含未存盘的工作流」开关，勾上后它们会以「未归档」出现在列表里，名字取自工作流分组标题或提示词摘要，JSON 从图片内嵌数据导出；不勾时工作流页只显示磁盘上真实存在的 .json 文件。这个选择存在 `~/.dsh-comfyui-gallery/settings.json`，重启插件仍然生效；如果插件配置里显式写了 `workflowFromImages`，则以配置为准，界面开关会提示被覆盖。已保存工作流的名称取文件名。

例图与出图数始终来自图片：即使关闭 `workflowFromImages`，已保存工作流仍会挂上匹配的出图，只是不再把"纯图片工作流"单独列出来。

列表只统计已解析的图片。新图片需要先在图片页运行「补全全库参数索引」，或在工作流页按提示补全，否则只能看到已解析部分（该提示仅在 `workflowFromImages` 开启时出现）。

## 相似图分组

- **pHash**：适合查找缩放、压缩或轻微修改后的近似重复图。
- **CLIP**：适合查找主题、构图或视觉内容相近的图片。

分组结果只用于人工检查，不会自动删除文件。

## 目录树与分组

工具栏的「目录」是一棵可展开的树：根目录 → 子目录逐级展开，每级显示该目录下的图片数；子目录超过 12 个的节点会折叠成「展开 N 个子目录」，避免一个大文件夹把整棵树撑满。

「分组」有三档：

- **不分组**：原来的网格。
- **按日期**：今天、昨天、最近 7 天、最近 30 天，再往前按月（YYYY-MM）。日常出图不建子目录也能按时间翻。
- **按项目目录**：取路径前两段作为一组（如 `projects / planrender`），用来把出图量大的项目单独摊开。

目录和分组可以叠加：先选目录再按日期分组，用来清理某个项目的多次重跑。

按日期分组时会多出一条跳转栏：全部日期 / 今天 / 昨天 / 前天 / 7 天前 / 30 天前，也可以直接选某一天。日期是真下推到查询的（`/list?from=&to=`），所以翻到很久以前不用一页页加载——选中某天后顶部会显示「当前只看 YYYY-MM-DD，共 N 张」，分组标题也换成该日期。分隔线以上的分组索引（如「今天 · 60」）可以在已加载内容里点击跳转。

## 删除图片

图片详情里点 **删除这张图片**，或在选择多张后点 **删除所选**，可以删掉图库中的原图。

- 二段式确认：先点删除，再点「确认删除」，10 秒内没有确认会自动取消。
- 单次最多 200 张，失败项单独报错，不会中断其余图片。
- 删除的是磁盘上的原图；ComfyUI 写在旁边的同名 `.json` 工作流文件会一起删掉。如果同目录下还有同名的其它图片（例如 `x.png` 与 `x.jpg` 并存），`.json` 会保留给留下来的那张。
- 索引、缩略图缓存、收藏/评分/标签记录会同步清理，删除后的图片不再出现在列表和搜索结果中。
- 不做回收站，删除后无法从插件内恢复。只允许删除配置中 `roots` 目录内的图片，目录外的 id 会被拒绝。

## 数据与隐私

图片索引、缩略图、收藏、备注、反推记录和相似度缓存都保存在本机 DSH 用户数据目录中。联网功能只在主动使用公开资料抓取时访问对应服务。

提交问题时，请移除日志中的本机路径、用户名、Token 和私人图片。
